# DEFAULT install: everything a local run needs, PINNED (==) to the versions the offline suite was
# verified against. Opt-in adapters (direct Anthropic, OpenTelemetry, the Databricks deploy stack) live in
# requirements-optional.txt so they are pinned and audited WITHOUT being installed by default.
#
# Policy (enforced by tests/test_dependency_policy.py, audited by .github/workflows/ci.yml):
#   * DECLARE WHAT YOU IMPORT -- a module imported by engine/ or a runner script is declared here (or in
#     requirements-optional.txt), never left to transitive resolution.
#   * PIN WHAT YOU DECLARE -- `==` in every requirements file; shared packages pin to the SAME version.
# Bump deliberately: `pip install -U <pkg>` -> `pytest -q` -> re-pin -> REGENERATE THE LOCK.
#
# This file is the INTENT (direct deps). requirements.lock.txt is the fully RESOLVED set -- every
# transitive pinned (universal: any platform, Python >= 3.11) -- and is what to install:
#   pip install -r requirements.lock.txt -r requirements-dev.txt
#   uv pip compile requirements.txt --universal --python-version 3.11 -o requirements.lock.txt   # regenerate
# tests/test_dependency_policy.py fails if the lock is stale relative to this file.
# See docs/concepts/security-and-telemetry.md §3.
