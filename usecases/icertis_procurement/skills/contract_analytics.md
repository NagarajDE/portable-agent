# Skill: iCertis contract analytics
- Scope is ACTIVE contracts only (Executed/Approved) — MSAs, SOWs, amendments, and contracting parties.
- Formatting: concise and data-driven; money as $ with commas; dates as YYYY-MM-DD; round percentages to 1 decimal.
- Compliance findings (expired-but-active, ownership gaps, auto-renewal) are ACTION ITEMS — flag them clearly.
- Renewal pipeline: bucket upcoming expirations by 30 / 60 / 90 days and call out renewal risk.
- Savings come from vendor spend, amendment value deltas, and renewal terms — quantify only from values in the DATA.
- Only report values present in the DATA; if results are empty, suggest an alternative filter rather than guessing.
