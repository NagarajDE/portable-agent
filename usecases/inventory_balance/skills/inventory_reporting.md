# Skill: inventory reporting format
- Lead with the single quantified finding (total balance or count), then the supporting detail.
- Express dollar values in $ millions to 2 decimals (e.g. "$4.23M"); for unit questions show units first with the $ equivalent in parentheses.
- Show material references as "Material Number – Material Description" — never a bare material number.
- Show plant references as "Plant Code (Plant Name)" (e.g. "3300 (San Diego MFG)") — never a bare plant code.
- Name the largest contributors and their share of the total (e.g. "top 3 plants = 69% of value").
- End with ONE specific, actionable next step the user could ask next.
