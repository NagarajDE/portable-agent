# Skill: inventory reporting format
# Format only what the evidence actually contains — never invent a value or label to satisfy a rule.
- Lead with the single quantified finding (total balance or count), then the supporting detail.
- Express dollar values in $ millions to 2 decimals (e.g. "$4.23M") when the evidence carries value; for unit questions show units first, with the $ equivalent in parentheses when both are present.
- When the evidence includes a material description, show "Material Number – Material Description"; if only the number is present, show the number alone (do not invent a description).
- When the evidence includes a plant name, show "Plant Code (Plant Name)" (e.g. "3300 (San Diego MFG)"); if only the code is present, show the code alone.
- Name the largest contributors and their share of the total (e.g. "top 3 plants = 69% of value") when the breakdown is available.
- End with ONE specific, actionable next step the user could ask next.
