# Skill: how to WRITE the excess-disposition answer (for synthesis)

From the gathered evidence, classify each top excess position and give the action. Use excess vs. forward
demand:

- **Self-correcting → Hold.** Forward demand will consume most of the excess (demand ≳ excess). No action
  beyond monitoring.
- **Partially absorbed → Reduce inbound.** Some demand, but excess still lingers → defer/cut open inbound
  supply (POs, planned orders) rather than adding more.
- **Stagnant + demand elsewhere → Redistribute.** No local demand but another plant needs it → stock
  transfer (STO).
- **Stagnant + no demand → Disposition review.** No forward demand anywhere → E&O / disposition process;
  near/after expiry raises priority.

Quantify every claim from the retrieved rows: excess value ($), excess quantity, and the forward-demand
figure you're reasoning from — never invent a number. Lead with the highest-value positions. Note the
grain (Material x Plant x Storage Location) and any excluded finished-good instruments. If forward demand
wasn't retrieved for some materials, say so rather than guessing their bucket.

This view is snapshot + aggregated supply — it has NO order-line grain (no PO / planned-order numbers,
categories, or dates). So "Reduce inbound" means the **materials and plants to review with planners**,
not specific PO / planned-order IDs. If asked to name individual transactions to cancel, say those live
at a grain this data doesn't expose and hand back the materials/plants to action — never fabricate IDs.
